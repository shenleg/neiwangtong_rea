仅提供 BaseLayout 所需的 bundle 与 CSS，不引入默认初始化器、Petstore、
standalone preset、OAuth 页面、外部字体、在线 validator 或 CDN。
上游文件中的 sourceMappingURL 是调试器用的映射提示，不影响页面离线运行；
本页不需要 source map，因此未复制体积较大的映射文件。

宿主 Go 路由应 embed assets/docs/* assets/swagger/* 并提供：
GET /docs -> assets/docs/index.html
GET /docs/init.js -> assets/docs/init.js
GET /docs/style.css -> assets/docs/style.css
GET /openapi.json -> assets/docs/openapi.json
GET /swagger-ui/swagger-ui-bundle.js -> assets/swagger/swagger-ui-bundle.js
GET /swagger-ui/swagger-ui.css -> assets/swagger/swagger-ui.css

文档页 CSP 应允许 script-src 'self'，style-src 'self' 'unsafe-inline'；
Swagger UI 使用内联样式，但本页无内联脚本或事件，不需要 unsafe-eval。
connect-src 仅允许 'self'；官方 CSS 内嵌图像需要 img-src 'self' data:。
不使用外部脚本、validator、URL 配置覆盖、鉴权或 token。
初始化器禁止跨源请求、Authorization、浏览器凭据和自动跟随重定向。
文档加载只读取 /openapi.json，不自动调用业务 GET 或任何 POST。
