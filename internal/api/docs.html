内网通 Agent API

统一发送 API · 基地址 · 初版本鉴权（仅本机回环）· 检测客户端中…

纪律说明：每次发送都是新的单次请求，不会自动重试；delivery 恒为 unknown，API 完成不代表送达。列表按实时数据库读取：撞上客户端写事务的那次请求返回 503，重试即可。
GET/health

核对并返回当前客户端实例身份（PID、窗口、文件摘要、会话）；客户端未运行或多实例时 503。

GET/contacts

返回全部联系人（contacts:[{name,user_id}]），附身份表名、页长与源文件摘要。加 ?name=精确名称 转为名称查询：唯一 200 unique；未命中 404 not_found；同名 409 ambiguous（返回全部候选，需人工选择）。

参数位置说明
namequery，可选联系人原始名称精确值（不是界面备注；保留大小写与空格）
GET/groups

返回全部群（groups:[{name,group_id}]）。加 ?name=精确名称 的语义同 /contacts。

POST/send/user

向原始用户发送一次消息。目标二选一：user_id（推荐，来自 /contacts）或 name（先做唯一解析，404/409 同上）。

字段类型说明
user_idstring目标用户 ID，与 name 二选一
namestring联系人原始名称，与 user_id 二选一
textstring必填。非空、UTF-8、无 NUL、按内容预算；字面 \n / \r\n 转实际换行
请求示例 
{
  "user_id": "a1b2c3d4...",
  "text": "hello world"
}
响应（200，调用事实） 
{ "attempt_id": "NWT-GW-...", "attempt_reserved": true,
  "preflight": { "pid": 1234, ... }, "call": { "invoked": true, ... },
  "delivery": "unknown" }
POST/send/group

向原生群发送一次消息。目标二选一：group_id（32 位十六进制）或 name（群名唯一解析）。

错误映射：400 目标/正文校验失败或 JSON 非法 · 404 名称未命中 · 409 同名歧义 · 503 客户端不可用/快照未配置/写事务竞态 · 502 已占用日志但调用失败（仍携带 attempt_id）。

INFO独立接收观察

API 完成不代表送达。需要接收证据时，用响应里的 attempt_id 调用命令行记录独立观察：

ipcexperiment.exe -exe 客户端路径 -observe NWT-GW-xxx -observe-kind recipient -observe-state one
